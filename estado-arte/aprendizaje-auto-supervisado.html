ESTADO DEL ARTE · 02

Aprendizaje auto-supervisado de representaciones del habla

El aprendizaje auto-supervisado busca reducir la dependencia de grandes colecciones de audio transcrito mediante objetivos de entrenamiento generados a partir de la propia señal acústica.

IDEA PRINCIPAL

¿Qué problema intenta resolver?

Uno de los principales problemas históricos del procesamiento del habla es la necesidad de disponer de grandes colecciones de grabaciones correctamente transcritas.

El aprendizaje auto-supervisado reduce esta dependencia utilizando el propio audio para generar objetivos de entrenamiento.

El modelo aprende primero una representación general a partir de audio sin transcribir y, posteriormente, dicha representación puede adaptarse a una tarea concreta utilizando una cantidad menor de datos etiquetados.

METODOLOGÍA GENERAL

¿Cómo funciona?

01

Audio sin etiquetar

El modelo recibe grandes cantidades de señal acústica sin necesidad de disponer de una transcripción humana.

02

Representación

La señal se transforma en representaciones internas que capturan información acústica y lingüística.

03

Objetivo auto-supervisado

Se ocultan, reconstruyen, discriminan o predicen determinadas partes de la propia señal.

04

Adaptación

El modelo preentrenado puede posteriormente adaptarse a una tarea concreta con una cantidad menor de datos etiquetados.

MODELOS PRINCIPALES

Modelos estudiados

Principales enfoques identificados en la revisión bibliográfica.

01

wav2vec 2.0

Procesa directamente la forma de onda, genera representaciones latentes, enmascara determinados intervalos temporales y utiliza aprendizaje contrastivo junto con cuantización.

Contrastive Learning Quantization Masked Learning
Ver referencia científica →
02

HuBERT

Utiliza agrupamiento para generar unidades acústicas discretas aproximadas y entrena al modelo para predecir dichas unidades en las regiones enmascaradas.

Clustering Masked Prediction Discrete Units
Ver referencia científica →
03

WavLM

Extiende el aprendizaje auto-supervisado incorporando conjuntamente predicción enmascarada y eliminación de ruido, con el objetivo de aprender representaciones útiles para múltiples tareas del habla.

Denoising Masked Prediction Speaker Full-stack Speech
Ver referencia científica →
04

XLS-R

Extiende wav2vec 2.0 al aprendizaje auto-supervisado multilingüe mediante preentrenamiento conjunto sobre grandes cantidades de habla perteneciente a numerosas lenguas.

Cross-lingual Multilingual Low-resource wav2vec 2.0

EVALUACIÓN

Transferencia a otras tareas

SUPERB

SUPERB permite estudiar hasta qué punto una representación preentrenada puede transferirse a diferentes tareas utilizando cabezas de predicción ligeras y manteniendo congelado el codificador principal.

Incluye tareas relacionadas con contenido lingüístico, características del hablante, semántica y procesamiento paralingüístico.

LIMITACIONES

Problemas todavía abiertos

Coste computacional

El preentrenamiento continúa requiriendo grandes volúmenes de audio y una elevada capacidad computacional.

Sesgo de los datos

Los modelos pueden reproducir distribuciones desequilibradas de lenguas, hablantes y condiciones acústicas.

Robustez

Una buena transferencia media no garantiza robustez frente a cambios de micrófono, ruido, acento, edad o pronunciación.

RELACIÓN CON LA TESIS

¿Por qué es relevante?

Las representaciones auto-supervisadas constituyen una base especialmente interesante para investigar sistemas acústicos capaces de adaptarse a nuevas condiciones utilizando cantidades reducidas de datos etiquetados.

Esta línea conecta directamente con el estudio de adaptación de dominio, aprendizaje continuo, personalización y desarrollo de representaciones robustas y transferibles.
