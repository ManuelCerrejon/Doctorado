01 · PROBLEMA Y OBJETIVO

Eliminar las cadenas de múltiples sistemas

Los sistemas tradicionales de traducción entre habla suelen estar formados por diferentes componentes conectados entre sí.

Por ejemplo, una traducción de habla a habla puede requerir primero reconocimiento automático, después traducción textual y finalmente síntesis de voz.

SeamlessM4T busca integrar estas capacidades dentro de un único sistema multilingüe y multimodal capaz de trabajar tanto con texto como con señales habladas.

02 · TAREAS

Un modelo, cinco modalidades de trabajo

ASR Speech → Text

Transcripción de una señal hablada en el mismo idioma.

S2TT Speech → Text Translation

La entrada es habla y la salida es texto traducido.

S2ST Speech → Speech Translation

Traducción directa desde habla hacia habla en otro idioma.

T2TT Text → Text Translation

Traducción automática convencional entre secuencias textuales.

T2ST Text → Speech Translation

El sistema recibe texto y genera habla traducida.

04 · REPRESENTACIÓN ACÚSTICA

w2v-BERT 2.0

PREENTRENAMIENTO AUTO-SUPERVISADO

1 millón de horas de habla

Antes de construir el sistema de traducción, los autores preentrenan un codificador acústico utilizando aproximadamente un millón de horas de audio abierto sin etiquetar.

Para ello utilizan w2v-BERT 2.0, combinando aprendizaje contrastivo y predicción enmascarada para obtener representaciones acústicas generales.

05 · ARQUITECTURA

Multitask UnitY

SeamlessM4T v1 es una adaptación multitarea de la arquitectura UnitY.

El usuario puede proporcionar cualquiera de las dos modalidades.

→

→

→
SEGUNDO PASO

Text-to-Unit

Si se necesita salida hablada, el texto se convierte en una secuencia de unidades acústicas.

→
SÍNTESIS

HiFi-GAN

Un vocoder multilingüe transforma las unidades acústicas finales en una forma de onda.

SPEECH-TO-SPEECH

Traducción en dos etapas

01

Comprender la entrada

El encoder procesa el audio o el texto proporcionado por el usuario.

02

Generar texto traducido

El decoder produce primero una secuencia textual en el idioma objetivo.

03

Generar unidades acústicas

El módulo Text-to-Unit utiliza el texto generado para predecir unidades discretas de habla.

04

Reconstruir audio

El vocoder HiFi-GAN convierte las unidades discretas en una señal hablada.

06 · DATOS

SeamlessAlign

Disponer de traducciones de habla correctamente alineadas para decenas de idiomas constituye uno de los principales problemas para entrenar este tipo de sistemas.

Por ello, los autores desarrollan mecanismos automáticos de alineación entre habla y texto utilizando espacios de representación compartidos.

SPEECH-TEXT

Alineaciones automáticas

> 443.000 h

Habla alineada automáticamente con información textual.

SPEECH-SPEECH

Traducción hablada

~29.000 h

Alineaciones directas entre grabaciones pertenecientes a distintos idiomas.

07 · ALINEACIÓN MULTIMODAL

SONAR

Espacio compartido entre idiomas y modalidades

SONAR proporciona representaciones a nivel de oración diseñadas para que contenidos equivalentes en diferentes idiomas se sitúen próximos dentro de un mismo espacio.

Este mecanismo se extiende a la modalidad acústica mediante un enfoque teacher-student, lo que permite buscar automáticamente correspondencias entre habla y texto en grandes colecciones.

08 · TRANSFERENCIA

Aprovechar modelos de traducción textual

El entrenamiento multitarea permite aprovechar conocimiento procedente de sistemas de traducción de texto a gran escala.

En particular, se utiliza conocimiento procedente de NLLB para mejorar el componente de traducción de habla a texto mediante distillation.

LIMITACIONES

Problemas todavía abiertos

Elevada escala

Los modelos publicados contienen aproximadamente 1,2 y 2,3 mil millones de parámetros.

Cobertura desigual

El número de lenguas admitidas depende de la modalidad y de la tarea realizada.

Dos etapas para generar habla

La generación speech-to-speech produce primero información textual y posteriormente unidades acústicas.

RELACIÓN CON LA TESIS

¿Qué aporta a mi línea de investigación?

SeamlessM4T representa un ejemplo claro de la evolución desde modelos especializados hacia sistemas capaces de compartir representaciones y componentes entre múltiples tareas y modalidades.

El uso de un codificador acústico auto-supervisado conecta directamente con las representaciones estudiadas anteriormente, mientras que su integración con texto y generación de habla muestra cómo dichas representaciones pueden incorporarse a sistemas multimodales.

Para la tesis resulta especialmente relevante estudiar si estas capacidades pueden mantenerse mediante arquitecturas más eficientes, adaptables y auditables y cómo se comportan frente a cambios en hablantes, ruido, idiomas o dominios específicos.

Importante: SeamlessM4T v1 y v2

Esta ficha se centra en SeamlessM4T v1, presentado en agosto de 2023.

Posteriormente se publicó SeamlessM4T v2, que introduce la arquitectura UnitY2, aumenta los datos de preentrenamiento y mejora especialmente el componente de generación de unidades acústicas.

Conviene mantener ambas versiones separadas para no atribuir al trabajo original características desarrolladas posteriormente.
