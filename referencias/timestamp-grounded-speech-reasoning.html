01 · PROBLEMA

¿Está el razonamiento realmente basado en el audio?

Los Large Audio-Language Models pueden producir explicaciones y cadenas de razonamiento antes de responder.

Sin embargo, generar una explicación coherente no garantiza que el modelo esté utilizando realmente la señal acústica para construirla.

El modelo puede aprovechar información lingüística del prompt, patrones aprendidos durante el entrenamiento o conocimiento previo para alcanzar una respuesta plausible.

Los autores plantean por ello que el razonamiento debe estar explícitamente vinculado a segmentos temporales de la señal.

PROBLEMA OBSERVADO

El modelo puede responder correctamente sin "escuchar" suficiente

El análisis de atención realizado por los autores muestra que los modelos base asignan relativamente poca atención a los tokens acústicos durante el razonamiento.

En cambio, determinados tokens del sistema pueden concentrar una parte muy superior de la atención.

IDEA PRINCIPAL

Listen First, Then Answer

Antes de producir la respuesta, el modelo debe identificar qué intervalo temporal contiene la evidencia relevante.

Posteriormente utiliza esa región dentro de su razonamiento antes de seleccionar la respuesta final.

GENERACIÓN DE TIMESTAMPS

Whisper + Dynamic Time Warping

Las alineaciones utilizadas para construir el conjunto de entrenamiento se obtienen mediante whisper-timestamped.

Este procedimiento utiliza información de cross-attention de Whisper junto con Dynamic Time Warping para estimar timestamps a nivel de palabra.

04 · STAGE 2

Timestamp-Grounded Reasoning

Saber localizar una palabra no garantiza que el modelo utilice correctamente esa capacidad durante una tarea de razonamiento.

La segunda etapa introduce reinforcement learning para incorporar la evidencia temporal dentro de la propia respuesta razonada.

REINFORCEMENT LEARNING

GRPO

01

Generar razonamientos

El modelo genera varias respuestas posibles para una pregunta relacionada con el audio.

02

Evaluar respuesta

Se comprueba si la opción final seleccionada es correcta.

03

Evaluar grounding

También se comprueba si el razonamiento incluye referencias temporales.

04

Optimizar

GRPO favorece las respuestas que combinan predicción correcta y evidencia temporal concisa.

FUNCIÓN DE RECOMPENSA

R = Ranswer + Rtg

La recompensa combina la corrección de la respuesta con un componente específico de timestamp grounding.

R ANSWER

Correctness

  • Respuesta correcta: recompensa
  • Respuesta incorrecta: sin recompensa
  • Mantiene el objetivo de la tarea

R TG

Timestamp Grounding

  • Favorece utilizar timestamps
  • Favorece evidencia concisa
  • Penaliza referencias excesivas

IMPORTANTE

Más timestamps no significa mejor explicación

El sistema no recompensa simplemente llenar el razonamiento de referencias temporales.

La recompensa está diseñada para favorecer un número reducido de regiones relevantes y evitar el timestamp spamming.

ATENCIÓN

Grounding hace que el modelo preste más atención al audio

Después del entrenamiento con timestamps, el modelo asigna una proporción superior de atención a los tokens acústicos, especialmente durante la generación del razonamiento.

Los autores identifican además capas donde la atención hacia el audio aumenta especialmente cuando el modelo está produciendo referencias temporales.

LIMITACIONES

Qué sigue abierto

Principalmente habla

Los experimentos del trabajo se centran en tareas basadas en señales habladas.

Grounding temporal

Localizar correctamente un intervalo no proporciona automáticamente una explicación frecuencial o espectral.

Alineaciones automáticas

Parte de los timestamps utilizados para entrenamiento se generan automáticamente mediante Whisper.

Reward sparse

La recompensa se aplica sobre propiedades globales de la respuesta y no supervisa cada paso intermedio del razonamiento.

RELACIÓN CON LA TESIS

Una referencia especialmente cercana al núcleo de la propuesta

Este trabajo demuestra que exigir grounding explícito puede modificar no solo la explicación producida por el modelo, sino también la forma en que utiliza la representación acústica.

Para la tesis, el timestamp puede considerarse un primer nivel de auditabilidad:

respuesta → evidencia → intervalo temporal verificable.

Sin embargo, la propuesta doctoral puede ir más allá combinando grounding temporal con evidencia espectral, fonética, prosódica o basada en eventos.

Una arquitectura jerárquica podría localizar primero una región, identificar después qué características acústicas son relevantes y finalmente convertir esas evidencias en reglas lingüísticas o neurodifusas.

Además, la confianza podría depender de la calidad del propio grounding: si el modelo no es capaz de localizar una evidencia suficientemente clara, debería reducir su confianza o abstenerse de responder.

IDEA DERIVADA PARA LA TESIS

Respuesta + Evidencia + Confianza

Una extensión natural consiste en no exigir únicamente una respuesta correcta y un timestamp.

El sistema podría producir:

predicción + intervalo temporal + evidencia acústica + explicación + nivel de confianza.
