01 · PROBLEMA Y OBJETIVO

Eliminar la frontera entre texto y habla

Muchos sistemas multimodales utilizan componentes distintos para procesar texto y habla y necesitan mecanismos específicos para conectar ambas modalidades.

SpiRit-LM estudia si un único modelo autoregresivo puede aprender directamente sobre secuencias que mezclen tokens textuales y acústicos.

De esta forma, cambiar entre texto y habla pasa a convertirse simplemente en continuar generando otro tipo de token dentro de la misma secuencia.

IDEA PRINCIPAL

Text + Speech = una sola secuencia

SpiRit-LM amplía un modelo textual Llama 2 de 7.000 millones de parámetros mediante entrenamiento continuo con tokens de habla y texto.

El modelo utiliza predicción del siguiente token independientemente de si dicho token representa texto o una unidad acústica.

12 · FEW-SHOT LEARNING

Aprender tareas mediante ejemplos

CAPACIDAD EMERGENTE

ASR, TTS y clasificación sin cambiar la arquitectura

Al igual que un LLM textual puede aprender temporalmente una tarea a partir de ejemplos incluidos en el prompt, SpiRit-LM puede hacerlo también entre modalidades.

Un prompt puede contener ejemplos de habla seguida de texto para representar ASR, o texto seguido de habla para representar TTS.

RESULTADOS

Few-shot en LibriSpeech

Modelo LS clean ASR ↓ LS clean TTS ↓ LS other ASR ↓ LS other TTS ↓ Intent ↑
SpiRit-LM Base 21,9 45,5 29,2 43,8 71,9
SpiRit-LM Base + ASR + TTS 6,0 6,7 11,0 7,9 75,8
SpiRit-LM Expressive 37,9 52,0 50,0 53,6 66,2

ASR se evalúa mediante WER y TTS mediante CER en un escenario de 10 ejemplos. Intent Classification utiliza accuracy con 30 ejemplos.

ABLATION

Interleaving es una pieza fundamental

Los experimentos muestran que continuar el entrenamiento únicamente con tokens de habla produce peor rendimiento que entrenar con secuencias intercaladas.

El interleaving ayuda simultáneamente a conservar las capacidades textuales originales y a desarrollar comprensión entre modalidades.

13 · EXPRESIVIDAD

Speech-Text Sentiment Preservation

Los autores introducen el benchmark STSP para comprobar si una continuación conserva el sentimiento expresado en el prompt.

En habla, dicho sentimiento puede estar codificado no solo mediante las palabras, sino mediante características expresivas de la voz.

SpiRit-LM Expressive utiliza los tokens adicionales de pitch y estilo precisamente para conservar mejor esta información.

LIMITACIONES

Aspectos abiertos

Unidades discretas

La tokenización inevitablemente descarta parte de la información presente en la señal original.

Alineaciones automáticas

Los datos utilizados para interleaving dependen de alineaciones palabra-audio obtenidas automáticamente.

Escala

El modelo conserva aproximadamente 7.000 millones de parámetros, además de los componentes necesarios para codificar y reconstruir habla.

Seguridad

Al heredar las capacidades generativas de un LLM también hereda riesgos relacionados con generación de contenido problemático.

RELACIÓN CON LA TESIS

¿Qué aporta a mi investigación?

SpiRit-LM demuestra que el habla no tiene por qué utilizarse únicamente como una entrada que posteriormente se transforma en texto.

Las dos modalidades pueden coexistir dentro de una representación autoregresiva común, permitiendo transferencia directa entre conocimiento textual y acústico.

La variante Expressive es especialmente relevante porque muestra que conservar únicamente contenido fonético resulta insuficiente para determinadas tareas.

Información como pitch, estilo y prosodia puede constituir evidencia necesaria para comprender correctamente una señal hablada.

Esto conecta directamente con la investigación sobre representaciones multimodales, explicabilidad acústica y razonamiento sobre información lingüística y no lingüística.
