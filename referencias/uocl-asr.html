01 · PROBLEMA Y OBJETIVO

Aprender continuamente sin etiquetas

Un sistema de reconocimiento desplegado puede recibir continuamente habla procedente de nuevos acentos, micrófonos, hablantes y dominios.

En Online Continual Learning, estas muestras forman un flujo no i.i.d. en el que el modelo desconoce a qué tarea pertenece cada batch.

Además, cada batch solamente puede utilizarse una vez y las fronteras entre tareas no son conocidas.

Este trabajo añade una dificultad adicional: los nuevos datos tampoco disponen de transcripciones.

ONLINE CONTINUAL LEARNING

Flujo continuo sin fronteras conocidas

El modelo recibe batches sucesivos pertenecientes a tareas desconocidas.

Debe utilizar cada batch para aprender nueva información manteniendo simultáneamente el conocimiento adquirido anteriormente.

02 · ESCENARIO

Tres restricciones de OCL

Unknown Boundaries Fronteras desconocidas

El sistema no recibe una señal indicando cuándo cambia el dominio.

Unknown Tasks Tarea desconocida

Cada batch llega sin indicar de qué acento, dominio o condición procede.

Single Pass Una sola oportunidad

Una vez procesado el batch, se pierde el acceso directo a esos datos.

03 · UOCL

Online Continual Learning sin etiquetas

SUPERVISED OCL

Audio + Ground Truth

  • Flujo continuo
  • Fronteras desconocidas
  • Transcripciones disponibles
  • Catastrophic forgetting

UNSUPERVISED OCL

Solo Audio

  • Flujo continuo
  • Fronteras desconocidas
  • Sin transcripciones
  • Pseudo-labels

05 · PSEUDO-LABELING

Tres estrategias

GREEDY CTC

CTC

  • Rápido
  • Sin decoder
  • Basado directamente en evidencia acústica

HYBRID

CTC + Decoder

  • Combina ambas distribuciones
  • Utiliza el LM interno del decoder
  • Mayor información lingüística

BERT-CTC

CTC + BERT

  • LM externo
  • Útil ante text-domain shift
  • Reduce dependencia del LM interno antiguo

06 · MÉTODOS OCL

Controlar el olvido

Fine-Tuning FT

Actualización directa sin ningún mecanismo explícito contra el olvido.

Experience Replay ER

Conserva una pequeña memoria con muestras de tareas anteriores y las mezcla con los nuevos datos.

AOS Averaging for Online CL

Mantiene un modelo adaptado y otro estable y transfiere gradualmente las actualizaciones.

07 · AOS

Modelo adaptado + modelo estable

Adapted Model

Aprende rápidamente de los nuevos batches.

→

Weight Averaging

Las actualizaciones se incorporan gradualmente al modelo final.

→

Final Model

Evoluciona más lentamente para reducir el olvido.

PROPUESTA DEL ARTÍCULO

AOS-U

Los autores modifican AOS específicamente para el escenario Unsupervised Online Continual Learning.

01

Adapted model → Pseudo-labels

El modelo que aprende más rápidamente se utiliza para generar las pseudoetiquetas.

02

Sin Knowledge Distillation

Se elimina la regularización KD utilizada originalmente por AOS para no limitar demasiado el aprendizaje del modelo adaptado.

03

Procesamiento múltiple

Antes de actualizar, cada batch se procesa varias veces aprovechando dropout y data augmentation.

04

K = 2

Los experimentos utilizan dos versiones aleatorias del batch antes de realizar una única actualización.

TEXT-DOMAIN SHIFT

BERT-CTC obtiene el mejor resultado UOCL

Cuando cambia también el dominio textual, el language model interno del decoder puede permanecer sesgado hacia el dominio original.

BERT-CTC incorpora información lingüística externa partiendo de las predicciones CTC y obtiene 12,01 WER medio.

RESULTADO CLAVE

Las pseudoetiquetas pueden provocar menos olvido

El aprendizaje supervisado dispone de objetivos más precisos y por tanto aprende mejor el nuevo dominio.

Sin embargo, precisamente por producir actualizaciones más fuertes también puede olvidar más conocimiento anterior.

En varios experimentos, el self-training no supervisado aprende de forma menos agresiva y reduce el catastrophic forgetting.

LIMITACIONES

Aspectos abiertos

Pseudo-label errors

El modelo aprende a partir de sus propias predicciones y puede propagar errores.

Equilibrio estabilidad-plasticidad

Aprender rápidamente mejora el nuevo dominio, pero puede aumentar el olvido.

Memoria

Experience Replay es eficaz, pero requiere almacenar audio o pseudoetiquetas anteriores.

Confianza

El trabajo utiliza self-training, pero no plantea como núcleo un mecanismo explícito de incertidumbre calibrada para decidir cuándo aprender.

RELACIÓN CON LA TESIS

El escenario más cercano a un sistema desplegado

UOCL plantea una situación especialmente realista para un sistema acústico que funciona continuamente.

Los datos llegan como un flujo, el sistema desconoce cuándo cambia el dominio y no dispone necesariamente de anotaciones humanas.

El trabajo demuestra que el self-training puede utilizarse para aprender continuamente, pero también deja abierta la cuestión de qué pseudoetiquetas deberían aceptarse.

Una extensión natural para la tesis consiste en combinar Online Continual Learning con estimaciones de incertidumbre y detección OOD.

Las muestras fiables podrían utilizarse para adaptar el modelo, mientras que las predicciones dudosas podrían descartarse, almacenarse temporalmente o requerir supervisión.

De este modo, la confianza pasaría a convertirse en un mecanismo de control del aprendizaje continuo.

IDEA DERIVADA PARA LA TESIS

Confidence-Guided Continual Adaptation

No aprender automáticamente de todas las predicciones.

Antes de actualizar el modelo, evaluar confianza, cambio de dominio y consistencia de la pseudoetiqueta.

Adaptar únicamente cuando exista evidencia suficiente para considerar fiable la actualización.
