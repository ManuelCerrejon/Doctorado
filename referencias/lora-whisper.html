01 · PROBLEMA Y OBJETIVO

Añadir idiomas sin destruir los anteriores

Los sistemas ASR multilingües deben aprender simultáneamente lenguas con diferentes cantidades de datos, pronunciaciones y características.

Esto puede producir interferencia: mejorar una lengua puede deteriorar el rendimiento en otra.

El segundo problema aparece al incorporar posteriormente una nueva lengua.

Realizar fine-tuning del modelo completo únicamente con los nuevos datos puede producir catastrophic forgetting de las lenguas aprendidas anteriormente.

IDEA PRINCIPAL

Un LoRA diferente para cada lengua

El modelo Whisper original permanece congelado y almacena la información compartida entre idiomas.

Cada lengua dispone de un módulo LoRA independiente encargado de capturar información específica.

03 · LOW-RANK ADAPTATION

W permanece congelada

ACTUALIZACIÓN

W' = W + BA

En lugar de modificar directamente la matriz original W, LoRA aprende dos matrices de bajo rango A y B.

Solo estos nuevos parámetros participan en el entrenamiento.

09 · LANGUAGE EXPANSION

Añadir cuatro lenguas nuevas

Los autores incorporan Danish, Greek, Welsh y Japanese después de haber entrenado el sistema sobre las cuatro lenguas base.

El objetivo es aprender las nuevas lenguas sin deteriorar Polish, Portuguese, Italian y Chinese.

CATASTROPHIC FORGETTING

Full fine-tuning destruye parte del conocimiento previo

Al realizar fine-tuning completo únicamente con las nuevas lenguas, el WER medio de las lenguas base pasa de 11,68 a 32,29.

Algunas lenguas se deterioran especialmente; Chinese alcanza 68,93 WER.

LIMITACIONES

Aspectos abiertos

Un módulo por lengua

El número total de módulos aumenta a medida que se incorporan idiomas.

Language ID

El sistema necesita conocer qué LoRA debe activarse durante la inferencia.

Adaptación supervisada

El entrenamiento de las nuevas lenguas utiliza pares de audio y transcripción.

Evaluación limitada

Los experimentos se realizan sobre ocho lenguas y Whisper-small.

RELACIÓN CON LA TESIS

¿Qué aporta a mi investigación?

LoRA-Whisper constituye un ejemplo especialmente claro de adaptación modular y eficiente.

Separar conocimiento compartido y conocimiento específico permite incorporar nueva información sin modificar continuamente todos los pesos del modelo.

Esta idea puede extenderse conceptualmente más allá de las lenguas: un sistema podría disponer de módulos específicos para hablantes, entornos, dispositivos o dominios acústicos.

El problema científico consistiría entonces en determinar automáticamente qué módulo debe utilizarse, cuándo crear uno nuevo, cuándo reutilizar uno existente y cuándo actualizarlo.

Estas decisiones podrían combinarse con mecanismos de incertidumbre y detección de cambio de distribución para evitar adaptaciones innecesarias o potencialmente perjudiciales.
