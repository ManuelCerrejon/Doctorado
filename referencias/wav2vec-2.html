01 · PROBLEMA Y OBJETIVO

¿Qué intenta resolver?

El trabajo se sitúa dentro del problema de la dependencia de grandes cantidades de habla correctamente transcrita para entrenar sistemas de reconocimiento.

wav2vec 2.0 plantea utilizar grandes cantidades de audio sin transcribir para aprender representaciones útiles del habla mediante aprendizaje auto-supervisado.

02 · METODOLOGÍA

Funcionamiento general

01

Forma de onda

El modelo procesa directamente la señal de audio.

↓
02

Representación latente

La señal se transforma en una representación interna aprendida por el modelo.

↓
03

Enmascaramiento

Determinados intervalos temporales de la representación son ocultados durante el entrenamiento.

↓
04

Cuantización

Se utilizan representaciones cuantizadas como candidatos durante el aprendizaje.

↓
05

Aprendizaje contrastivo

El modelo aprende a distinguir la representación correcta frente a un conjunto de candidatos.

IDEA CLAVE

Menor dependencia de audio transcrito

El resultado relevante para el estado del arte es que el preentrenamiento mediante grandes cantidades de audio sin transcribir permite reducir considerablemente la cantidad de datos etiquetados necesarios para construir sistemas competitivos de reconocimiento automático del habla.

03 · DATASETS

Datos utilizados

El trabajo diferencia entre los datos sin transcribir utilizados durante el preentrenamiento y los datos etiquetados utilizados posteriormente para adaptar el modelo al reconocimiento automático del habla.

10 min → 960 h

04 · MODELO

Arquitectura de wav2vec 2.0

La arquitectura combina un codificador convolucional, un módulo de cuantización y una red Transformer encargada de obtener representaciones contextualizadas.

ENTRADA

Forma de onda

Audio crudo normalizado antes de entrar en el codificador.

→
ENCODER

CNN

Siete bloques convolucionales transforman la señal en representaciones latentes.

→
CONTEXTO

Transformer

Construye representaciones contextualizadas utilizando información de toda la secuencia.

↕
OBJETIVOS

Cuantización

Las representaciones latentes se discretizan para generar los objetivos de la tarea contrastiva.

  • Dimensión FFN: 3.072

WAV2VEC 2.0 LARGE

317 M parámetros

  • Dimensión FFN: 4.096

05 · PREENTRENAMIENTO

Aprendizaje auto-supervisado

Durante esta fase no se utilizan las transcripciones. El objetivo consiste en aprender representaciones generales directamente a partir del audio.

01

Extracción de características

El codificador convolucional transforma la forma de onda en una secuencia de representaciones acústicas latentes.

02

Enmascaramiento

Se selecciona aleatoriamente una proporción de posiciones de la representación latente y se enmascaran intervalos consecutivos.

03

Contextualización

El Transformer procesa las representaciones parcialmente ocultas y genera una representación contextual para cada instante temporal.

04

Cuantización

Las representaciones producidas por el codificador se transforman en unidades discretas mediante product quantization y Gumbel Softmax.

05

Pérdida contrastiva

Para cada posición enmascarada, el modelo debe identificar la representación cuantizada correcta entre ella y diferentes distractores.

06

Diversidad del codebook

Se añade una segunda pérdida para favorecer que el modelo utilice de forma diversa las entradas disponibles en los codebooks.

Inicio de máscara p = 0,065
Longitud de máscara M = 10
Frames enmascarados ≈ 49 %
Duración media ≈ 299 ms
Distractores K = 100
Codebooks G = 2
Entradas / codebook V = 320
Optimizador Adam

06 · FINE-TUNING

Adaptación a reconocimiento del habla

Modelo preentrenado

Una vez terminado el aprendizaje auto-supervisado, se incorpora una capa lineal de salida sobre las representaciones producidas por el Transformer.

→

CTC

El modelo se adapta utilizando audio transcrito y una función de pérdida Connectionist Temporal Classification.

→

ASR

Finalmente se obtienen predicciones de caracteres para LibriSpeech o fonemas para TIMIT.

Detalle importante

Durante las primeras 10.000 actualizaciones del fine-tuning únicamente se entrena el clasificador de salida. Posteriormente también se actualiza el Transformer.

El codificador convolucional de características permanece congelado durante el fine-tuning.

Además, los autores aplican una variante de SpecAugment sobre las representaciones internas para reducir el sobreajuste.

07 · EVALUACIÓN

Resultados principales

El rendimiento se evalúa principalmente mediante Word Error Rate (WER) sobre los conjuntos test-clean y test-other de LibriSpeech.

RELACIÓN CON LA TESIS

¿Qué aporta a mi línea de investigación?

wav2vec 2.0 constituye un ejemplo fundamental del uso de representaciones auto-supervisadas como base para sistemas de procesamiento del habla que requieren menos información etiquetada.

Este paradigma resulta especialmente relevante para estudiar posteriormente adaptación de dominio, personalización, aprendizaje continuo y robustez frente a nuevas condiciones acústicas.
