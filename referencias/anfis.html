01 · PROBLEMA Y OBJETIVO

Combinar conocimiento humano y aprendizaje a partir de datos

Los sistemas difusos permiten representar conocimiento mediante reglas lingüísticas del tipo IF-THEN.

Sin embargo, determinar manualmente una base adecuada de reglas y ajustar correctamente las funciones de pertenencia puede resultar difícil.

ANFIS introduce una arquitectura adaptativa capaz de representar un sistema de inferencia difusa dentro de una estructura de red.

Sus parámetros pueden ajustarse automáticamente utilizando pares entrada-salida.

IDEA PRINCIPAL

Fuzzy System + Adaptive Learning

ANFIS combina reglas fuzzy interpretables con mecanismos de aprendizaje utilizados en redes adaptativas.

El sistema puede construir un mapeo entrada-salida a partir de reglas if-then y pares de datos observados.

02 · REGLAS

Takagi-Sugeno

Para explicar la arquitectura, el artículo utiliza un ejemplo sencillo con dos entradas x e y y dos reglas.

RULE 2

THEN

f₂ = p₂x + q₂y + r₂

LAYER 1

Fuzzification

La primera capa calcula el grado de pertenencia de cada entrada a los conjuntos difusos.

Por ejemplo, un valor x puede pertenecer parcialmente a conceptos como:

Low μLow(x)
Medium μMedium(x)
High μHigh(x)

Premise parameters

Los parámetros que controlan la forma y posición de las funciones de pertenencia reciben el nombre de premise parameters.

MEMBERSHIP FUNCTION

μA(x)

El artículo utiliza principalmente funciones de pertenencia generalizadas con forma de campana.

Los parámetros controlan características como centro, anchura y pendiente.

LAYER 2

Firing Strength

RULE ACTIVATION

wᵢ = μAᵢ(x) · μBᵢ(y)

Se combinan los grados de pertenencia de las premisas para obtener la fuerza de activación de cada regla.

LAYER 3

Normalized Firing Strength

NORMALIZATION

w̄ᵢ = wᵢ / Σwⱼ

La fuerza de cada regla se normaliza respecto a la activación total.

De esta forma puede interpretarse cuánto contribuye relativamente cada regla al resultado.

LAYER 4

Consequent

RULE OUTPUT

w̄ᵢ (pᵢx + qᵢy + rᵢ)

Cada regla produce una salida local definida mediante una combinación lineal de las entradas.

Los parámetros p, q y r son los consequent parameters.

LAYER 5

Salida global

OUTPUT

f = Σ w̄ᵢ fᵢ

La salida final se obtiene agregando las contribuciones de todas las reglas.

05 · ENTRENAMIENTO

Hybrid Learning

Una de las contribuciones centrales de ANFIS es separar el aprendizaje de los dos tipos de parámetros.

El algoritmo combina Least Squares Estimation y Gradient Descent.

Forward Pass Backward Pass
Premise parameters Fixed Gradient Descent
Consequent parameters Least Squares Estimate Fixed
Señal Node outputs Error rates
01

Forward Pass

Se mantienen fijos los parámetros de las funciones de pertenencia.

02

Least Squares

Se calculan los parámetros consecuentes óptimos para las premisas actuales.

03

Error

Se compara la salida de ANFIS con la salida objetivo.

04

Backward Pass

El error se propaga hacia las primeras capas.

05

Gradient Descent

Se actualizan los premise parameters.

06

Repetir

El proceso continúa durante las sucesivas épocas.

VENTAJA

Reducir el espacio de búsqueda por gradiente

Cuando los premise parameters permanecen fijos, la salida es lineal respecto a los consequent parameters.

Por ello estos últimos pueden obtenerse mediante Least Squares en lugar de aprender todos los parámetros únicamente con Gradient Descent.

APRENDIZAJE ONLINE

El artículo también contempla adaptación muestra a muestra

Jang distingue entre batch learning y pattern / online learning.

En el caso online, los parámetros pueden actualizarse después de presentar cada par entrada-salida.

También se discute el uso de un forgetting factor para reducir progresivamente la influencia de datos antiguos.

MUY IMPORTANTE PARA LA TESIS

Más rendimiento no garantiza reglas más interpretables

El propio artículo observa que reducir excesivamente el número de funciones de pertenencia puede mantener un buen ajuste numérico.

Sin embargo, las reglas pueden perder parte de su significado como descripciones locales estructuradas.

El sistema se aproxima entonces progresivamente al comportamiento de una caja negra.

CONOCIMIENTO HUMANO

¿Aprender o mantener las funciones de pertenencia?

Jang discute explícitamente que no siempre resulta apropiado modificar automáticamente las membership functions.

Si existen suficientes datos, aprenderlas puede mejorar el ajuste del sistema.

Pero cuando los datos son escasos, las funciones definidas por especialistas pueden contener conocimiento que no está suficientemente representado en el conjunto de entrenamiento.

IMPORTANTE

ANFIS no fue propuesto como método XAI para audio

El artículo de 1993 estudia modelado no lineal, identificación de sistemas y predicción de series temporales.

Su relevancia para esta tesis reside en utilizar su arquitectura como fundamento para construir mecanismos neurodifusos específicamente acústicos.

RETO CIENTÍFICO

Evitar reglas decorativas

Para que un sistema neurodifuso sea realmente explicable, las reglas deben participar en la decisión.

No debería utilizarse un gran modelo neuronal para decidir primero y generar después una regla fuzzy que simplemente imite esa decisión.

LIMITACIONES PARA NUESTRA LÍNEA

Problemas que debemos resolver

Rule explosion

Aumentar el número de entradas y funciones de pertenencia puede hacer crecer rápidamente el número de reglas.

Conceptos semánticos

Una función aprendida matemáticamente no garantiza automáticamente conceptos lingüísticos comprensibles.

Deep embeddings

Aplicar fuzzy logic directamente a cientos de dimensiones de un embedding acústico dificultaría la interpretación.

Rendimiento

La interpretabilidad debe mantenerse sin producir una pérdida excesiva de precisión.

Faithfulness

Las reglas deben demostrar que influyen realmente en la salida.

Escalabilidad

La arquitectura clásica debe adaptarse a modelos acústicos modernos de alta dimensionalidad.

RELACIÓN CON LA TESIS

Una de las bases metodológicas más importantes de la línea

ANFIS proporciona el principio básico para combinar capacidad de aprendizaje y reglas lingüísticas dentro de una misma arquitectura.

La tesis puede trasladar esta idea al procesamiento moderno del habla y del audio.

Un encoder acústico podría detectar representaciones relevantes y transformarlas posteriormente en un conjunto reducido de descriptores interpretables.

Estos descriptores podrían actuar como entradas de un sistema neurodifuso encargado directamente de producir parte de la decisión.

De esta forma, las reglas no serían una explicación añadida después de la predicción, sino un componente efectivo del mecanismo de inferencia.
