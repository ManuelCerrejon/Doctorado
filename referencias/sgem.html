01 · PROBLEMA Y OBJETIVO

Adaptarse cuando el dominio cambia

Un sistema ASR puede encontrar durante la inferencia hablantes, palabras, acentos o ruidos que no aparecieron durante su entrenamiento.

En el escenario considerado por SGEM no se dispone de transcripciones del nuevo dominio ni de los datos originales utilizados para entrenar el reconocedor.

La adaptación debe realizarse utilizando únicamente la propia grabación recibida durante test.

TEST-TIME ADAPTATION

Sin etiquetas y sin datos fuente

SGEM utiliza una configuración single-utterance TTA.

Para cada grabación recibida, el modelo realiza varias actualizaciones no supervisadas utilizando únicamente esa misma señal.

MOTIVACIÓN

¿Por qué no basta con greedy decoding?

Métodos anteriores como SUTA utilizaban las predicciones obtenidas mediante greedy decoding para realizar la adaptación.

Los autores argumentan que este enfoque no representa adecuadamente la naturaleza secuencial de modelos ASR modernos, especialmente cuando utilizan decodificación autoregresiva o beam search.

IDEA PRINCIPAL

Adaptarse a nivel de secuencia

SGEM utiliza beam search para obtener una secuencia de salida plausible y utiliza los logits asociados a esa secuencia para construir los objetivos de adaptación.

02 · METODOLOGÍA

Pipeline SGEM

01

Target Utterance

El sistema recibe una única grabación sin transcripción.

02

Beam Search

Se exploran diferentes hipótesis de transcripción y se selecciona la secuencia más plausible.

03

Logit Acquisition

La secuencia seleccionada se introduce nuevamente en el modelo para obtener los logits correspondientes a cada timestep.

04

Generalized Entropy

Se reduce la incertidumbre de las predicciones mediante una generalización de la entropía de Shannon.

05

Negative Sampling

Se penalizan las clases que presentan probabilidades suficientemente bajas.

06

Adaptation

Los parámetros seleccionados del ASR se actualizan utilizando ambos objetivos.

07

Decode

El modelo adaptado genera la transcripción final de la grabación.

04 · GENERALIZED ENTROPY

Rényi Entropy

En lugar de utilizar únicamente la entropía convencional, SGEM introduce Rényi entropy con un parámetro α.

Esto permite controlar la forma en que se penaliza la incertidumbre de las distribuciones generadas por el reconocedor.

Los timesteps dominados por el blank token se ignoran para reducir el problema de desequilibrio entre clases.

05 · NEGATIVE SAMPLING

Penalizar clases poco plausibles

INTUICIÓN

No sé cuál es la clase correcta, pero sí cuáles parecen incorrectas

Como no existe ground truth, SGEM identifica como negativas las clases cuya probabilidad se encuentra por debajo de un determinado umbral.

Posteriormente penaliza la probabilidad acumulada asignada a esas clases.

OBJETIVO FINAL

L = LGEM + λNSLNS

La adaptación combina Generalized Entropy Minimization y Negative Sampling mediante una suma ponderada.

MUY IMPORTANTE

SGEM no es aprendizaje continuo

La adaptación es episódica.

Después de procesar cada grabación, el modelo vuelve a sus parámetros originales preentrenados.

Por tanto, el conocimiento aprendido con una muestra no se conserva para la siguiente.

LIMITACIONES

Qué todavía no resuelve

No aprende continuamente

El modelo se reinicia después de cada utterance y no conserva la adaptación.

Coste de inferencia

Cada muestra requiere varias actualizaciones mediante backpropagation.

Confianza inicial

La adaptación continúa dependiendo de las distribuciones producidas por el propio modelo.

No siempre mejora

En algunas condiciones concretas de ruido, el modelo sin adaptación puede obtener mejores resultados.

RELACIÓN CON LA TESIS

¿Qué aporta a mi investigación?

SGEM demuestra que un sistema ASR puede modificar sus parámetros durante la propia inferencia sin utilizar transcripciones del nuevo dominio.

Esto resulta especialmente relevante para escenarios donde aparecen progresivamente nuevos hablantes, acentos, canales o condiciones de ruido.

Sin embargo, SGEM reinicia el modelo después de cada grabación.

Por tanto, resuelve adaptación local pero no aprendizaje continuo.

Para la tesis, una extensión natural consiste en conservar únicamente las adaptaciones que sean fiables, acumular conocimiento útil entre muestras y utilizar incertidumbre para decidir cuándo actualizar o restaurar el modelo.
