01 · PROBLEMA Y OBJETIVO

¿Pertenece esta señal al mundo que conoce el modelo?

Los clasificadores neuronales pueden producir predicciones muy seguras incluso cuando reciben entradas muy diferentes de las utilizadas durante el entrenamiento.

En aplicaciones reales, esta situación puede aparecer cuando cambia la tarea, el tipo de sonido, el idioma o el dominio.

Los autores estudian si el espacio de representación aprendido por un modelo acústico puede utilizarse para detectar estas entradas fuera de distribución.

OUT-OF-DISTRIBUTION

ID cerca · OOD lejos

La hipótesis es que las muestras pertenecientes al dominio de entrenamiento ocupan regiones próximas dentro del embedding space.

Una muestra OOD debería aparecer más aislada y tener vecinos más alejados.

Antes de calcular distancias, los embeddings se normalizan mediante norma L2.

05 · INFERENCIA

Distancia al k-ésimo vecino

01

Nueva muestra

Se recibe un audio x* durante inferencia.

02

Embedding

El modelo produce z* para esa muestra.

03

Euclidean Distance

Se calcula la distancia de z* a los embeddings de entrenamiento.

04

k Nearest Neighbours

Se ordenan los vecinos desde el más cercano al más lejano.

05

dₖ

Se utiliza la distancia al k-ésimo vecino como señal OOD.

06

Threshold

Si la muestra está demasiado alejada, se considera OOD.

DISTANCIA

dₖ = ||zₖ − z*||₂

Cuanto mayor sea la distancia al vecino de referencia, mayor será la evidencia de que la muestra es fuera de distribución.

VENTAJA IMPORTANTE

El threshold no necesita ejemplos OOD

γ puede establecerse únicamente utilizando datos in-distribution.

Los autores seleccionan el threshold para aceptar una proporción elevada, por ejemplo 95 %, de muestras ID.

No es necesario conocer previamente qué tipos de OOD aparecerán.

16 · ¿POR QUÉ FUNCIONA?

El embedding contiene más información que el softmax

La capa de clasificación transforma una representación rica en un conjunto reducido de logits.

Dos muestras diferentes pueden producir probabilidades elevadas para una misma clase aunque se encuentren en regiones distintas del embedding space.

Analizar directamente las representaciones permite detectar esa separación.

VENTAJAS

Método sencillo y flexible

No OOD training Solo ID

No necesita disponer previamente de ejemplos fuera de distribución.

Non-parametric No distribution assumption

No asume una forma estadística concreta para el embedding space.

Model flexible MobileNet / EfficientNet

Puede aplicarse sobre distintas arquitecturas.

Faiss Efficient search

Permite realizar búsquedas eficientes en espacios grandes.

LIMITACIONES

Aspectos abiertos

OOD parecido

Cuando ID y OOD representan tareas acústicas muy similares, la separación empeora.

Memoria

Es necesario conservar representaciones del conjunto de referencia.

Dependencia del embedding

Si el modelo aprende representaciones poco adecuadas, las distancias pueden no reflejar correctamente el cambio de distribución.

k

El valor óptimo depende del dominio in-distribution.

Clasificación

El trabajo estudia tareas de clasificación de audio y habla, no ASR secuencial.

OOD binario

Detectar que una muestra es desconocida no indica automáticamente qué ha cambiado.

RELACIÓN CON LA TESIS

Una señal para decidir cuándo el sistema ha entrado en terreno desconocido

Este trabajo resulta directamente relevante para la detección de cambios de distribución.

Un sistema adaptativo podría mantener un espacio de representaciones correspondientes a condiciones conocidas.

Cuando una nueva muestra aparece muy alejada de esas representaciones, el sistema podría evitar utilizarla automáticamente para actualizar el modelo.

El OOD score podría combinarse con confidence y calibración para decidir si aceptar, adaptar, crear un nuevo componente o abstenerse.

IDEA DERIVADA PARA LA TESIS

Representation-Guided Adaptive Audio

Audio ↓ encoder ↓ embedding ↓ nearest neighbours ↓ OOD score ↓ combinar con confidence ↓ aceptar / adaptar / nueva memoria / abstenerse.
