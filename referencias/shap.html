01 · PROBLEMA Y OBJETIVO

Unificar métodos de explicación

Antes de SHAP existían diferentes métodos para explicar predicciones de modelos complejos, pero no estaba claro cómo se relacionaban entre sí.

Los autores muestran que varios de estos métodos pueden expresarse dentro de una misma familia: los métodos de atribución aditiva de características.

SHAP proporciona un marco común en el que cada característica recibe una contribución para una predicción concreta.

IDEA PRINCIPAL

De una predicción base a la predicción final

SHAP interpreta la salida de un modelo como la suma de un valor base y las contribuciones de cada característica.

Cada valor φᵢ indica cuánto contribuye una característica a desplazar la predicción respecto al valor de referencia.

EXPLANATION MODEL

g(z') = φ₀ + Σ φᵢ z'ᵢ

φ₀ representa el valor base.

Cada φᵢ representa la contribución atribuida a una característica.

02 · INTUICIÓN

Características como jugadores

Los valores de Shapley proceden de la teoría de juegos cooperativos.

Podemos imaginar que cada característica de la entrada es un jugador que participa en una coalición.

La predicción del modelo constituye el resultado obtenido por la coalición de características.

El objetivo consiste en repartir de forma fundamentada ese resultado entre los distintos participantes.

01

Sin la característica

Se considera una coalición donde la característica i todavía no está presente.

02

Añadir característica i

Se incorpora la característica a la coalición.

03

Medir el cambio

Se observa cuánto cambia la predicción cuando se incorpora i.

04

Repetir

El cálculo se considera para diferentes subconjuntos de características.

05

Promediar

La contribución final tiene en cuenta los diferentes órdenes y contextos en que aparece la característica.

BASE VALUE

E[f(x)]

La explicación comienza desde una predicción esperada de referencia.

Las contribuciones positivas y negativas de las características desplazan ese valor hasta la predicción de la instancia.

EJEMPLO CONCEPTUAL

Base → contribuciones → predicción

Predicción base = 0,40

Característica A = +0,25

Característica B = +0,10

Característica C = −0,05

Predicción final = 0,70

03 · PROPIEDADES

Tres requisitos fundamentales

PROPERTY 1

Local Accuracy

La suma de las contribuciones debe reconstruir la predicción del modelo para la instancia explicada.

PROPERTY 2

Missingness

Una característica considerada ausente debe recibir contribución cero.

PROPERTY 3

Consistency

Si aumenta la contribución marginal de una característica, su atribución no debería disminuir.

RESULTADO TEÓRICO

Una única solución

Dentro de la familia de modelos de atribución aditiva, los autores demuestran que existe una única solución que satisface simultáneamente Local Accuracy, Missingness y Consistency.

Esa solución corresponde a los valores de Shapley.

05 · KERNEL SHAP

LIME + Shapley

Kernel SHAP utiliza una formulación basada en regresión lineal sobre representaciones binarias de características presentes y ausentes.

La diferencia respecto a Linear LIME reside en la elección específica de la función de ponderación, la pérdida y la regularización.

Con estas elecciones, la regresión recupera los valores de Shapley.

01

Seleccionar subconjuntos

Se generan combinaciones de características presentes y ausentes.

02

Evaluar el modelo

Se obtiene la salida de la caja negra para cada combinación.

03

Shapley Kernel

Cada coalición recibe un peso específico.

04

Regresión lineal

Se ajusta un modelo de atribución aditiva.

05

SHAP values

Los coeficientes obtenidos representan las contribuciones de las características.

06 · DEEP SHAP

Aproximación para redes profundas

El artículo introduce también Deep SHAP como una aproximación específica para modelos profundos.

Esta estrategia conecta las ideas de SHAP con mecanismos de atribución utilizados por DeepLIFT.

El objetivo es aproximar valores SHAP evitando evaluar explícitamente todas las posibles coaliciones de características.

PROBLEMA COMPUTACIONAL

2ᴹ coaliciones

Considerar todas las combinaciones posibles resulta inviable cuando el número de características M es elevado.

Por ello, los métodos prácticos necesitan aproximaciones, muestreo o explotar la estructura del modelo.

IMPORTANTE

El artículo original no es de audio

SHAP se presenta como un marco general para interpretar predicciones de modelos.

La aplicación a habla o sonido requiere decidir posteriormente cuáles serán las características acústicas que actuarán como "jugadores".

APLICACIÓN A AUDIO

¿Qué sería una característica?

Frames Temporal units

Intervalos concretos de la grabación.

Time-Frequency Spectrogram regions

Regiones localizadas en tiempo y frecuencia.

Phonemes Phonetic units

Segmentos fonéticos alineados con la señal.

Words Linguistic units

Palabras relacionadas con regiones acústicas.

Events Sound events

Fuentes o eventos acústicos identificables.

Prosody Acoustic descriptors

Pitch, energía, duración o pausas.

EJEMPLO ACÚSTICO

Evento A + Evento B + Prosodia

En una señal acústica, SHAP podría estudiar cuánto cambia una predicción cuando se dispone de diferentes combinaciones de evidencias.

El problema científico pasa a ser cómo representar correctamente la ausencia de una de esas evidencias.

PROBLEMA EN AUDIO

Las características acústicas no son independientes

Los componentes de una señal de audio presentan fuertes dependencias temporales, espectrales y lingüísticas.

Un fonema depende de los frames vecinos, una palabra depende de una secuencia y un evento puede solaparse con otros sonidos.

Por ello, eliminar una característica sin tener en cuenta sus dependencias puede producir entradas acústicamente irreales.

LIMITACIONES PARA AUDIO

Aspectos críticos

Coste combinatorio

Una señal puede contener miles de frames o bins, haciendo inviable trabajar directamente con todas las coaliciones.

Background

La elección de una referencia o distribución de fondo afecta a las atribuciones.

Dependencias

Tiempo, frecuencia y fonética no pueden tratarse siempre como características independientes.

Perturbación OOD

Las combinaciones de presencia y ausencia pueden producir audio fuera de distribución.

Resolución

Valores SHAP sobre miles de elementos no constituyen por sí mismos una explicación comprensible.

Fidelidad semántica

Una puntuación elevada debe relacionarse después con una evidencia acústica interpretable.

RELACIÓN CON LA TESIS

De contribuciones numéricas a evidencias acústicas

SHAP ofrece un marco sólido para asignar contribuciones a las características utilizadas por un modelo.

Sin embargo, aplicar directamente SHAP a cada bin de un espectrograma produciría una explicación demasiado extensa y difícil de interpretar.

Para la tesis resulta más interesante estudiar unidades acústicas jerárquicas:

frames → segmentos → fonemas / eventos → conceptos acústicos.

Los valores de atribución podrían agregarse sobre estas unidades y posteriormente convertirse en variables lingüísticas.

Un sistema neurodifuso podría utilizar finalmente estas variables para construir reglas auditables.

IDEA DERIVADA PARA LA TESIS

Hierarchical Acoustic SHAP

En lugar de explicar miles de bins independientemente, agrupar la evidencia acústica en unidades progresivamente más interpretables.

De esta forma podrían obtenerse atribuciones a nivel temporal, fonético, prosódico y semántico.
