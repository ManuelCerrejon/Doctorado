01 · PROBLEMA Y OBJETIVO

Equivocarse con mucha confianza

Los modelos ASR modernos pueden deteriorar su precisión cuando aumenta el ruido.

Sin embargo, una degradación del reconocimiento no implica necesariamente una reducción equivalente de la confianza.

Bajo ruido intenso, Whisper puede producir tokens incorrectos y asignarles aun así probabilidades elevadas.

Los autores estudian sistemáticamente este fenómeno y proponen un calibrador post hoc específicamente dirigido a esas predicciones sobreconfiadas.

HALLAZGO PRINCIPAL

El WER empeora antes que la calibración

El WER comienza a aumentar claramente por debajo de aproximadamente 0 dB.

En cambio, ECE y NCE permanecen relativamente estables hasta aproximadamente −5 / −10 dB.

Bajo ruido más severo, la calibración también empieza a deteriorarse rápidamente.

INTERPRETACIÓN

Durante un tiempo el modelo "sabe que está fallando"

El reconocimiento puede empezar a degradarse antes de que las estimaciones de confianza pierdan completamente su utilidad.

Con ruido extremo, esa capacidad también termina deteriorándose y aparecen errores altamente confiados.

LOW SNR 10–20 %

errores con confidence > 0,7

Sobreconfianza severa

Bajo los niveles más intensos de ruido, una proporción considerable de tokens incorrectos continúa recibiendo una confianza elevada.

SELECTIVIDAD

No calibrar todo

Si el clasificador considera que un token no presenta sobreconfianza, sus logits permanecen sin modificar.

Solo los tokens identificados como problemáticos pasan al calibrador.

09 · SELECTIVE CALIBRATOR

Temperature Scaling específico por token

SCALING

logits'ᵢ = logitsᵢ / Tᵢ

El calibrador predice una temperatura diferente para cada token seleccionado.

Tᵢ siempre es mayor que 1, por lo que el procedimiento únicamente puede reducir la confianza.

TOKEN TEMPERATURE

Tᵢ = 1 + softplus(MLP(fᵢ))

El mismo vector de características utilizado para detectar sobreconfianza sirve también para calcular cuánto debe reducirse la confianza.

MATIZ IMPORTANTE

La calibración selectiva no mejora todas las condiciones

Entre aproximadamente −5 y +5 dB, el método puede producir un ligero deterioro de algunas métricas de calibración.

Su principal beneficio aparece precisamente en las condiciones de ruido severo para las que fue entrenado.

RESULTADO INTERESANTE

La confianza no depende solo de la probabilidad máxima

El clasificador utiliza conjuntamente información acústica, semántica y de incertidumbre.

Los top-5 logits, el token embedding y la representación Mel aportan información complementaria para detectar errores sobreconfiados.

LIMITACIONES

Aspectos abiertos

Whisper-medium.en

El estudio experimental utiliza este modelo como caso principal.

Ruido sintético

Las condiciones acústicas son controladas y no representan toda la variabilidad de ruido real.

Acoustic feature global

La representación acústica se comparte entre todos los tokens de la utterance.

Token alignment

No se utiliza todavía una representación acústica alineada específicamente con cada token.

Mid-SNR

En ciertas condiciones moderadas pueden aparecer pequeñas degradaciones de calibración.

Post hoc

El sistema mejora las probabilidades, pero no hace que Whisper reconozca mejor.

RELACIÓN CON LA TESIS

Especialmente relevante para Whisper en condiciones reales

Esta referencia muestra que la robustez de un ASR no debe evaluarse únicamente mediante WER.

También debemos estudiar si el sistema conoce cuándo su transcripción ha dejado de ser fiable.

Para la tesis, una señal de sobreconfianza podría utilizarse para impedir que una transcripción dudosa alimente mecanismos de adaptación continua.

También podría activar una segunda decodificación, solicitar otra grabación, marcar regiones para revisión humana o provocar la abstención del sistema.

IDEA DERIVADA PARA LA TESIS

Confidence-Controlled Continual Adaptation

Audio ↓ Whisper ↓ predicción + confidence ↓ overconfidence detector ↓ ¿predicción fiable? ↓ sí → utilizar / adaptar ↓ no → descartar / abstenerse / supervisar.
