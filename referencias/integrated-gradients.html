Integrated Gradients

Axiomatic Attribution for Deep Networks

Sundararajan, Taly & Yan · ICML 2017

XAI Feature Attribution Gradients Baseline Post hoc

REFERENCIA

Información bibliográfica

Primer autor Mukund Sundararajan
Año 2017
Publicación ICML 2017 · PMLR 70
Páginas 3319–3328

Sundararajan, M., Taly, A., & Yan, Q. (2017). Axiomatic Attribution for Deep Networks. Proceedings of the 34th International Conference on Machine Learning, PMLR 70, 3319–3328.

01 · PROBLEMA

Atribuir una predicción a las características de entrada

Dado un modelo F y una entrada x, el objetivo consiste en asignar a cada característica de x una contribución a la predicción producida por F.

Los autores observan que varios métodos de atribución existentes incumplen propiedades que consideran fundamentales para una explicación.

02 · AXIOMAS

Dos requisitos fundamentales

SENSITIVITY

Sensibilidad

Si una característica cambia respecto al baseline y ese cambio altera la predicción, debe recibir una atribución distinta de cero.

IMPLEMENTATION INVARIANCE

Invarianza

Dos redes funcionalmente equivalentes deberían producir las mismas atribuciones aunque estén implementadas de forma diferente.

03 · BASELINE

Explicar respecto a una referencia

COMPARACIÓN

x' → x

Integrated Gradients no explica la entrada de forma absoluta.

Calcula la atribución respecto a una entrada de referencia x' que representa conceptualmente la ausencia de la característica.

04 · MÉTODO

Integrar gradientes a lo largo del camino

01

Seleccionar baseline

Se define una entrada de referencia x'.

02

Interpolar

Se construyen puntos a lo largo de la línea recta entre x' y x.

03

Calcular gradientes

Se obtiene el gradiente de la salida respecto a cada característica.

04

Integrar

Los gradientes se acumulan a lo largo de todo el recorrido.

05

Attribution Map

Cada característica recibe finalmente una puntuación de contribución.

FORMULACIÓN

Integrated Gradients

IGᵢ(x) = (xᵢ − x'ᵢ) ∫₀¹ ∂F(x' + α(x − x')) / ∂xᵢ dα

05 · COMPLETENESS

Las contribuciones deben sumar el cambio de salida

PROPIEDAD

Σ IGᵢ(x) = F(x) − F(x')

La suma de todas las atribuciones corresponde a la diferencia entre la predicción obtenida para la entrada y la obtenida para el baseline.

06 · PROPIEDADES

Características del método

Sin modificar la red Post hoc

No requiere cambiar la arquitectura original.

Gradientes estándar Backpropagation

Utiliza operaciones de gradiente disponibles en redes neuronales.

Sensitivity Axiom

Diseñado para cumplir el requisito de sensibilidad.

Implementation Invariance Axiom

La explicación depende de la función representada y no de detalles equivalentes de implementación.

IMPORTANTE

El artículo original no estudia audio

Los autores demuestran Integrated Gradients sobre modelos de imagen, modelos de texto y un modelo relacionado con química.

Su inclusión en este Estado del arte se debe a que constituye un método general de atribución que posteriormente puede aplicarse a modelos acústicos.

LIMITACIONES PARA AUDIO

El baseline es una decisión crítica

Baseline

Definir qué significa "ausencia de sonido" o ausencia de una característica no siempre es trivial.

Camino

Las entradas intermedias entre baseline y señal pueden no corresponder a audio natural.

Resolución

Un mapa de miles de bins tiempo-frecuencia puede resultar difícil de interpretar.

Fidelidad semántica

Una atribución numérica no se transforma automáticamente en una explicación lingüística comprensible.

RELACIÓN CON LA TESIS

Herramienta de atribución, no explicación final

Integrated Gradients puede utilizarse para localizar qué partes de una representación acústica influyen en una decisión.

Para la tesis podría funcionar como un primer nivel de evidencia:

modelo → atribución → regiones acústicas relevantes.

Posteriormente estas regiones podrían agruparse mediante unidades temporales, fonéticas o espectrales y transformarse en conceptos comprensibles.

Finalmente, un sistema neurodifuso podría utilizar dichas evidencias para construir reglas lingüísticas auditables.
