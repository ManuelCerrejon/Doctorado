01 · PROBLEMA Y OBJETIVO

ASR potente bajo restricciones Edge

Modelos como Whisper proporcionan reconocimiento robusto y de vocabulario abierto, pero continúan requiriendo cantidades importantes de memoria y cómputo.

Los dispositivos Edge suelen utilizar aceleradores orientados a inferencia de precisión reducida.

Edge-ASR estudia hasta qué punto diferentes técnicas de Post-Training Quantization pueden reducir esos requisitos sin provocar una degradación excesiva del WER.

IMPORTANTE

Es un benchmark, no un nuevo modelo ASR

Los autores mantienen las arquitecturas originales de Whisper y Moonshine y comparan diferentes procedimientos de cuantización.

El objetivo es estudiar qué configuración ofrece el mejor compromiso entre precisión y eficiencia.

02 · POST-TRAINING QUANTIZATION

Reducir precisión sin reentrenar el ASR

QUANTIZATION

FP32 → INT8 / INT4 / INT3

Los pesos y activaciones de alta precisión se representan mediante un número menor de bits.

El objetivo es reducir almacenamiento, movimiento de datos y coste aritmético.

GREEN AI

El coste no son solo las operaciones

El movimiento de pesos y activaciones entre memoria y procesador puede dominar la latencia y el consumo energético.

Por ello Edge-ASR reporta Memory I/O además del número de operaciones.

RESULTADO

w8-a8 conserva muy bien el rendimiento

La cuantización con pesos de 8 bits y activaciones de 8 bits mantiene un WER muy próximo al modelo de punto flotante en las cinco variantes.

CAPACIDAD DEL MODELO

Los modelos grandes toleran mejor 4 bits

Whisper Small, Whisper Base y Moonshine Base mantienen relativamente bien su rendimiento.

Whisper Tiny y Moonshine Tiny son mucho más sensibles a la reducción de precisión.

08 · ULTRA-LOW BIT

¿Hasta dónde puede llegar PTQ?

Modelo FP32 WER Mejor w3-a16 Método
Whisper Base 10,32 12,15 SpQR
Moonshine Base 9,99 10,67 SpQR
3 BIT VIABLE

con métodos avanzados

2 bits falla

En los experimentos, todos los métodos PTQ producen WER inaceptablemente elevado con pesos de 2 bits.

Los autores señalan que por debajo de 3 bits sería necesario recurrir a entrenamiento consciente de cuantización.

09 · OUTLIERS

¿Por qué algunos métodos fallan a 3 bits?

Los autores analizan la curtosis de pesos y activaciones para estudiar la presencia de distribuciones con colas pesadas y outliers.

A precisiones extremas, unos pocos valores de gran magnitud pueden dificultar enormemente la representación cuantizada.

Los métodos híbridos como QUIK y SpQR protegen una pequeña fracción de outliers utilizando mayor precisión.

HYBRID QUANTIZATION

< 1 % outliers → 16 bit

El resto de los pesos puede mantenerse a baja precisión.

Esta estrategia resulta especialmente útil en el escenario de 3 bits.

10 · GRANULARIDAD

Per-channel vs Per-group

PER-CHANNEL

Más simple

Puede funcionar razonablemente bien en modelos de mayor capacidad.

PER-GROUP

Más fino

Resulta especialmente útil para modelos pequeños, donde reduce el efecto del ruido de cuantización.

GRANULARITY RESULT

GPTQ

Entre AWQ, GPTQ y TesseraQ, GPTQ obtiene el menor WER medio de forma consistente en las configuraciones de granularidad evaluadas.

11 · SYMMETRIC vs ASYMMETRIC

Hardware simple vs mayor precisión

SYMMETRIC

z = 0

Más sencillo para hardware de inferencia.

ASYMMETRIC

Zero-point

Introduce mayor flexibilidad para representar el rango de valores.

RESULTADO

7 de 8 métodos

La cuantización asimétrica supera a la simétrica en siete de los ocho algoritmos comparados en este experimento.

12 · WEIGHT CLIPPING

HALLAZGO PARA EDGE

Encoder y decoder tienen cuellos de botella distintos

En el encoder, el coste está fuertemente condicionado por el tamaño de activaciones y el Memory I/O.

En el decoder, el tamaño de los pesos tiene un peso relativo mayor.

PROPUESTA DE DESPLIEGUE

Encoder w8-a8 + Decoder w4-a16

Los autores señalan esta combinación como una configuración que podría considerarse para escenarios Edge.

No debe interpretarse como una nueva fila experimental completa de la tabla, sino como una recomendación derivada del análisis de los dos componentes.

14 · CALIBRATION ABLATION

¿Importa qué audio usamos para calibrar?

Los autores comparan 256 muestras de Common Voice con 256 muestras de LibriSpeech Dev.

En general, el cambio de corpus produce variaciones relativamente pequeñas entre los métodos analizados.

La diferencia máxima observada en este estudio es inferior a 1,82 puntos de WER.

MATIZ

Más datos de calibración no siempre es mejor

Al aumentar de 256 a 512 muestras, la mayoría de algoritmos permanece estable.

AWQ, sin embargo, sufre una degradación muy pronunciada.

Los autores la relacionan con activaciones extremas que dominan el cálculo de las escalas.

IMPORTANTE

Edge-ASR todavía no es una evaluación física completa en un dispositivo Edge

El trabajo cuantifica model size, Memory I/O y BOPs.

Sin embargo, no presenta como núcleo del benchmark medidas físicas de energía, temperatura o latencia sobre varios dispositivos reales.

Los propios autores dejan el despliegue hardware-specific como trabajo futuro.

16 · LIMITACIONES

Aspectos abiertos

Dos familias

Solo se evalúan Whisper y Moonshine.

Transformers

No se comparan todavía RNN, Conformer, State Space Models o Canary.

Ocho PTQ

No incluye todas las técnicas modernas, por ejemplo algunos métodos basados en rotaciones.

Dynamic Quantization

No forma parte del benchmark.

Hardware-specific

No se estudian todavía configuraciones específicas para múltiples aceleradores Edge.

Energía física

BOPs y Memory I/O aproximan el coste, pero no sustituyen una medida energética real.

RELACIÓN CON LA TESIS

Especialmente relevante para nuestro trabajo con Whisper

Edge-ASR proporciona una metodología directamente reutilizable para estudiar modelos de reconocimiento de propósito general.

La tesis podría aplicar diferentes niveles de cuantización sobre un modelo adaptado al dominio objetivo y evaluar simultáneamente WER y coste.

También sería posible estudiar si todos los componentes del modelo necesitan la misma precisión.

Encoder, decoder, capas acústicas y adaptadores podrían utilizar configuraciones diferentes dependiendo de su sensibilidad.

IDEA DERIVADA PARA LA TESIS

Mixed-Precision Adaptive Whisper

Whisper adaptado ↓ analizar sensibilidad por componente ↓ asignar bits dinámicamente ↓ encoder / decoder / LoRA con distinta precisión ↓ minimizar:

WER + memoria + latencia + energía.

EXTENSIÓN

Resource-Aware Dynamic Precision

batería alta → mayor precisión

batería baja → menor precisión

audio sencillo → modelo compacto

audio difícil / baja confianza → mayor capacidad
